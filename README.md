# weldpack

Weld encode/decode helpers for pack payloads in pipelines.

**Site:** https://theworker02.github.io/weldpack/

## Install / run

```bash
git clone https://github.com/theworker02/weldpack.git
cd weldpack
node src/cli.js
node --test
```
