Overview

Weld encode/decode helpers for pack payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/weldpack.git
cd weldpack
node src/cli.js --help
node --test
